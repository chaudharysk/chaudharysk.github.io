Hermes Watcher

A physical status display that brings Hermes Agent activity to the desk through an animated face, sound cues, and alerts on a SenseCAP Watcher.

PythonMQTTEmbedded C

Hermes Agent → Python hooks → MQTT → SenseCAP Watcher

The idea

See what an agent is doing without repeatedly checking a chat window, and notice when it needs a human answer.

What I built

  • Python hooks and an observer plugin that publish agent activity, permission requests, and clarification questions over MQTT.
  • A C firmware integration with a translucent animated face, blinking, state-dependent expressions, and seven locally embedded sound cues.
  • Persistent amber alerts for requests that need attention, while preserving the Watcher’s native touch controls.
  • Request IDs, display acknowledgements, and a diagnostic tool to trace the path from the agent to the device.

The human in the loop

Hermes runs on the computer. The Watcher displays activity and calls attention to requests; answers and approvals stay in the original Hermes chat or terminal.

Open source

The repository includes the firmware patch, laptop integration, a reference Mosquitto setup, installation tutorial, protocol documentation, and offline Python tests.
