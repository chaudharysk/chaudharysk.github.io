Hardware & software

ARBD1: from board to dashboard

Practical hardware and software work for ARBD1, an Arduino-based educational electronics board.

FirmwarePythonMQTT

The challenge

Make the board’s sensors and actuators easier to control, read, and understand through software.

My work

  • Developed firmware for a learning board with environmental sensors and onboard peripherals.
  • Created a Python library for hardware control, including sensor readings, RGB lighting, navigation switches, and a buzzer.
  • Built a GUI for monitoring sensor readings and worked on device-to-dashboard data flow using MQTT.

The connection

The project brought together embedded programming, communication protocols, a usable Python interface, and a visual way to inspect what the hardware was doing.
