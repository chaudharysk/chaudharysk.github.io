The alternate uploaded illustration is preserved locally as a reference. The real photograph is not in the current deployable output.

templates/animated-avatar.html uses native SVG silhouette clipping around the original illustration. The face, pose, broad shoulders, and source image pixels are retained. No portrait-frame swap occurs. The desktop renders it as a companion; selecting it opens direct links to the profile and JARVIS.

A same-position open/closed screenshot comparison found changed pixels only in the eye region, with no body/background differences. Browser checks verify the unchanged source URL, fixed bounds, two-second duration, and static reduced-motion state. Image copies were verified by SHA-256 against the uploads.

Previous generated portrait sprites remain historical assets and are not loaded by this desktop. A photo extraction explored during design is retained only in ignored local QA files and is not served.
