# Natural guide voices

Current edition: three natural character-style voices, selected by the user on 7 November 2026. These are original portfolio performances using Microsoft neural speech, not copied actor performances or show recordings.

- JARVIS: en-GB-RyanNeural; rate -4%, pitch -2Hz. Calm British delivery.
- FRIDAY: en-GB-SoniaNeural; default rate/pitch. Warm conversational British delivery.
- EDITH: en-US-AriaNeural; default rate/pitch. Clear American delivery.

There are 3 greeting MP3s and 81 reply MP3s: the 24 reviewed portfolio topics plus outside-scope, thanks and unavailable-notes responses for each guide. Only the curated public answer text was sent for generation. File generation used edge-tts 7.3.1 with Microsoft's online neural speech; files are self-hosted and loaded on demand. No speech-service request, key or microphone is used by website visitors.

The player uses the natural recordings for every guide. Volume and pitch-preserving speaking pace are adjustable. Spoken replies and interface cues are visitor choices. There is no page-load autoplay. Closing, minimising, hiding the page and Stop controls end playback. The legacy Windows desktop voice files have been removed from the active output. The reviewed text knowledge remains the source of facts; a future factual edit should regenerate the matching narration.
