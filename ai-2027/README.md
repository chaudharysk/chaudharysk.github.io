# Learn AI in 2027

A self-study plan for language models and agents, for people who have used Python and studied engineering maths. The six parts cover three things in parallel: maths and code, language models, and applications. The estimated 540–760 hours include the projects, evaluation and research reading.

## Edit the course

- The full notes are in assets/study-plan.md. The material assignments and lesson summaries are in source/build_data.py.
- source/rebuild.py generates the HTML pages and downloadable diagram. The shared markup is in source/render.py, with styles and small browser features in assets/style.css and assets/app.js.
- From ai-2027, run **python3 source/rebuild.py** using Python 3.10 or newer. Commit the source edits and the resulting HTML/SVG together.
- To preview the GitHub Pages paths, run **python3 -m http.server 4173** from the repository root and open **http://localhost:4173/ai-2027/**.

The site uses ordinary links under /ai-2027/. The original hash links forward to the corresponding pages. Saved readings and completion checks use the existing browser storage keys.
