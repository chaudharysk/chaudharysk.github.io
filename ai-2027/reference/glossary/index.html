Key terms

Short definitions from tokens and embeddings to RAG, RLHF and KV cache.

No terms match. Try a different word.

Token
A piece of input text represented by an integer ID. A token can be a word, part of a word, a punctuation mark or a byte-based piece.
Embedding
A learned vector representation. Token embeddings turn IDs into model inputs. Sentence embeddings make it possible to compare the meaning of longer pieces of text.
BPE
Byte-pair encoding builds a vocabulary by repeatedly merging pairs of symbols that occur frequently.
Attention
A calculation that uses queries and keys to decide how much to weight value vectors. A causal mask limits each position to information available so far.
Pretraining
Learning model weights on a broad data distribution. A causal language model learns to predict the next token from previous tokens.
SFT
Supervised fine-tuning uses examples of desired outputs. The chat template and loss mask determine which tokens supply supervision.
LoRA
Low-rank adaptation trains small update matrices while keeping the base weights frozen.
QLoRA
Adapter training with a quantised frozen base model. The run still needs memory for activations and the trainable adapter.
RLHF
Reinforcement learning from human feedback. A common recipe fits a reward model to human preferences and then uses that reward to improve a policy.
DPO
Direct preference optimisation fits a policy on preferred and rejected completions, usually relative to a reference policy.
PPO
Proximal policy optimisation is a family of policy-gradient methods. PPO-Clip clips the policy ratio in its training objective to discourage overly large updates.
GRPO
Group relative policy optimisation estimates advantages from rewards for a group of completions sampled for the same prompt.
RLVR
Reinforcement learning with verifiable rewards uses an automatic checker as the source of reward, such as exact agreement with a numerical answer.
RAG
Retrieval-augmented generation puts selected documents or chunks in the model's input so it can use them when answering.
AI agent
A system that uses a model to choose actions, calls tools, reads the results and updates state while working toward a goal.
Context and memory
Context is the information available to the current model call. External memory stores information that can be added to a future call.
KL divergence
A directional measure of difference between probability distributions. A training objective may use it to discourage a policy from drifting from a reference.
Perplexity
The exponential of mean token negative log-likelihood in natural logs. Compare it on the same data with compatible tokenisation, masking and context rules.
Macro-F1
The arithmetic mean of the per-class F1 scores. Each class contributes equally, including classes with relatively few examples.
Calibration
How well a system's predicted probabilities match observed outcomes. For example, cases labelled 80% confident should be correct about 80% of the time.
Confidence interval
An interval from a statistical procedure that expresses uncertainty under a specified sampling design and assumptions.
KV cache
Attention keys and values saved from earlier tokens in a sequence so decoding can reuse them. Its memory cost grows with the cached sequence.
Ablation
A comparison that removes or changes one component to measure what it contributes under controlled conditions.
Distillation
Training a student model using outputs, probabilities or trajectories from a teacher model.
