Training methods

See what data each method uses, what changes and where to use it.

Comparison
MethodMain signalWhat changes?What the student should understand
PretrainingMain signalSelf-supervised prediction on a corpusWhat changes?Model weightsWhat the student should understandData, objective and compute jointly shape the resulting model.
Continued pretrainingMain signalFurther corpus dataWhat changes?Model weightsWhat the student should understandDomain adaptation can also cause forgetting or regressions.
SFTMain signalDemonstrated responsesWhat changes?Weights or adaptersWhat the student should understandThe supervised target and masking matter.
RLHFMain signalHuman feedback, often converted into a reward signalWhat changes?Depends on the recipe; commonly a reward model and then policyWhat the student should understandFeedback provenance, reward quality and optimisation are separate design choices.
DPOMain signalPreferred/rejected pairsWhat changes?Policy weights or adaptersWhat the student should understandStandard offline DPO avoids a separately trained reward model and an online rollout loop.
RLAIFMain signalAI feedbackWhat changes?Depends on the optimisation methodWhat the student should understandThis describes feedback origin, not a single optimiser.
RLVRMain signalAutomatically verified outcomesWhat changes?Policy weightsWhat the student should understandVerification defines the reward source; it can still be flawed.
GRPOMain signalGroups of sampled responses and rewardsWhat changes?Policy weightsWhat the student should understandThis is an optimisation approach, not a synonym for RLVR or all reasoning training.
DistillationMain signalTeacher outputs, probabilities or trajectoriesWhat changes?Student weightsWhat the student should understandA student can inherit teacher errors as well as useful behaviour.
RAG or external memoryMain signalRetrieved documents or stored informationWhat changes?Context and external storageWhat the student should understandKnowledge access changes without necessarily changing weights.
Agent executionMain signalTool observations, state and model decisionsWhat changes?Context and possibly the environmentWhat the student should understandRunning a tool loop is not automatically reinforcement learning.
Test-time computationMain signalAdditional sampling, search or verificationWhat changes?Usually computation and contextWhat the student should understandMore work helps only if the task and selection method benefit.
