Notes and exercises

Start with a two-hour self-check. Multiply compatible matrices and write down the output shape. Differentiate a small expression and solve a conditional probability problem. Explain how you would choose a learning rate using development data. Write a Python function that batches records and handles malformed input.

Use the self-check to find what you have forgotten. For each weak topic, read a short explanation, work through an example and try a different problem the next day. If Python functions, arrays or basic algebra are new to you, learn them first. The hour estimates assume you have seen them before.

FoundationsStudy and doUse the PyTorch tensor and autograd basics. Revise Python functions, indexing, loops, files, JSON, exceptions, environments and basic Git use through the project.
Language modelsStudy and doUse SLP chapter 2 and HF introductory model/tokenizer material. Trace text to token IDs, embeddings, logits, probabilities and generated tokens at an introductory level. Distinguish a base model from an instruction-tuned model.
ApplicationsStudy and doChoose a small collection of public technical documents. Run one model call and a simple literal-search baseline. Write 10–20 development questions with source IDs.

Completion check: rerun the script in a fresh session, explain a token versus an embedding, show the model input/output and name three observed failures. No fine-tuning or agent framework is required yet.

Keep the document collection small enough to inspect manually. Use stable source versions and record permission/licence information. A local program can simulate tool calls while external model access is being set up.
