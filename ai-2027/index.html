Learn AI in 2027

Train a small language model, build a document assistant and learn how to test both.

For anyone who has used Python and studied engineering maths. The first part helps you get back up to speed.

Start part 1 See the study plan
  • 6 parts
  • 3 tracks in parallel
  • 540–760 study hours

Course outline

  1. 1.

    Python and maths refresher

    A script you can run again, with notes on three things it gets wrong.

    20–30 hoursComplete
  2. 2.

    Machine learning and NLP basics

    A comparison of simple text classifiers, with an explanation of their errors.

    80–110 hoursComplete
  3. 3.

    Build a language model

    A small trained language model and a document assistant with measured results.

    120–160 hoursComplete
  4. 4.

    Fine-tuning and agents

    An SFT experiment and an agent that handles failed tool calls.

    100–140 hoursComplete
  5. 5.

    RLHF and reinforcement learning

    A DPO comparison, a toy RL run and examples of a reward checker getting things wrong.

    100–140 hoursComplete
  6. 6.

    Evaluation and a final project

    Working code, a results table, an error analysis and instructions for running it.

    120–180 hoursComplete

Study in parallel

Work on all three tracks in each part. For example, practise gradients while you write attention and try document search.

Maths and code

Language models
Tokens, transformers, training and learning from feedback.
Applications
Retrieval, tools, agents and running models.
