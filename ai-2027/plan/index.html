Study plan

Read across each part to see what to study together. Open a part for its readings, exercises and completion checks.

  • Maths and code
  • Language models
  • Applications

1. Python and maths refresher

20–30 hoursComplete

Maths and code
Python, arrays, tensor shapes and a few maths exercises.
Language models
Tokens, messages and next-token prediction. Run an existing model.
Applications
Collect a few documents, search them and make a model call.

What you’ll make A script you can run again, with notes on three things it gets wrong.

2. Machine learning and NLP basics

80–110 hoursComplete

Maths and code
Probability, gradients, loss functions, data splits, linear models and neural networks.
Language models
N-grams, TF-IDF, embeddings, encoders and decoders.
Applications
Search documents by keyword, label relevant results and define an output format.

What you’ll make A comparison of simple text classifiers, with an explanation of their errors.

3. Build a language model

120–160 hoursComplete

Maths and code
The chain rule, matrix operations, optimisation and numerical stability.
Language models
BPE tokenisation, causal attention, decoder training and validation loss.
Applications
Embedding search, RAG, source citations and handling missing information.

What you’ll make A small trained language model and a document assistant with measured results.

4. Fine-tuning and agents

100–140 hoursComplete

Maths and code
KL divergence, regularisation, confidence intervals and fair comparisons.
Language models
Training data, SFT, LoRA, chat templates and checks for worse performance.
Applications
A Python tool loop, argument validation, saved state and error handling.

What you’ll make An SFT experiment and an agent that handles failed tool calls.

5. RLHF and reinforcement learning

100–140 hoursComplete

Maths and code
States, actions, rewards, expected return, policy gradients and preference likelihoods.
Language models
Reward models, DPO, RLHF, and small PPO and GRPO calculations.
Applications
Compare a fixed workflow with an agent. Test memory and repeated tool failures.

What you’ll make A DPO comparison, a toy RL run and examples of a reward checker getting things wrong.

6. Evaluation and a final project

120–180 hoursComplete

Maths and code
Paired comparisons, calibration, effect size and experimental design.
Language models
One research question, model design choices and inference costs.
Applications
Measure speed and memory, serve a small system and finish your project.

What you’ll make Working code, a results table, an error analysis and instructions for running it.
