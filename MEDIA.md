All public assets are in `assets/media/`. The photos were inspected; no claim of a successful repair, specific project outcome, or project date has been added where the media does not establish one.

The ARBD1 videos preserve the original H.264 video and audio with streaming metadata moved to the beginning. The other videos are H.264/AAC web copies with reduced bitrate. Public photos contain decoded pixels without EXIF/GPS metadata, and video container metadata is removed. The original files are untouched. The web media collection is approximately 40.5 MB; every individual file is below 10 MB. Videos are requested only when opened in the viewer.

Caption tracks contain recognizable spoken mathematics questions and replies for the Raspberry Pi clips, plus sound descriptions for background conversation or music. These are concise accessibility captions, not full song transcriptions. Each gallery item also has a visible description. The viewer supports native controls, fullscreen, captions, previous/next navigation, Escape, focus restoration, and playback cleanup when closed.
