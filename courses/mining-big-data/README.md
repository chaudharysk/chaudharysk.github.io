# Pattern mining and grocery recommendations

**Course:** Mining Big Data, COMP SCI 7306, University of Adelaide, 2025.

**Assessment:** Part 3b, group report for pattern mining and recommender systems.

**My recorded score:** 89.5 / 100 (group assessment).

| File | What it contains |

The project combines FP-Growth pattern mining, recency-aware pattern scoring, and collaborative filtering for grocery recommendations. It compares recommendation approaches using precision, recall, F1, and MAP. The report records small gains from the hybrid approach alongside increased computational cost and discusses limitations.

## Team and my contribution

The report is co-authored by **Shashikant Chaudhary, Joel Varghese Thomas, and Anoop Ajith**. It is group work, rather than an individual implementation of every component.

My contribution covered exploratory analysis and the frequent-pattern-mining component, including support/confidence experiments, recency weighting, and a tunable combination of support and recency for scoring patterns. I also contributed the executive summary, introduction, exploratory-analysis discussion, and pattern-mining section of the report. Joel contributed collaborative filtering; Anoop contributed integration and evaluation. This attribution follows the attached contribution statement and report reflections.
